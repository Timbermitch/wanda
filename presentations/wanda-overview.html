The problem

A pipeline fails at 2 a.m. Someone loses their morning.

When a Microsoft Fabric data pipeline breaks, an engineer spends 1–2 hours doing mechanical detective work — reading failure logs, opening each notebook, querying the lakehouse to see what actually exists, cross-referencing all of it.

What Wanda does

It walks the same evidence chain a senior engineer would — in seconds.

🔎

1 · Pull the run

Finds the failed pipeline run and the exact activity that broke.

📓

2 · Read the source

Opens the failing notebook and reads the offending code.

🗄️

3 · Verify the data

Queries the SQL endpoint to confirm what tables & columns truly exist.

📄

4 · Report

Writes a definitive, evidence-backed root-cause report. No guessing.

The agent decides each step itself — different failures take different paths. That's what makes it genuinely agentic, not a script.
